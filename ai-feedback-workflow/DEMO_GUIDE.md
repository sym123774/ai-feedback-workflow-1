# 演示录屏指南

## 📺 3-5 分钟录屏脚本

```
大家好，今天展示的是一个 AI 用户反馈智能分析工作流。
这是一个面向产品运营人员的工具，可以自动分析用户反馈并生成结构化报告。
```

### 场景介绍（30 秒）
```
【展示 README 中的场景与痛点表格】

传统方式下，产品运营人员需要手动阅读和分类用户反馈，
每天花费 2-3 小时。使用这个 AI 工作流，5 分钟就能完成。
```

### 功能演示（2 分钟）

#### 演示 1：命令行运行
```
1. 打开终端，进入项目目录
2. 运行：python main.py
3. 展示实时分析过程
4. 展示最终的结构化输出结果
```

#### 演示 2：查看 JSON 结果
```
1. 打开 analysis_result.json
2. 展示结构化的分析结果
3. 重点展示：分类、优先级、情感分析、建议动作
```

#### 演示 3：API 调用（可选）
```
1. 启动 API 服务：python api_server.py
2. 使用 curl 或 Postman 调用
3. 展示 API 返回结果
```

在开发过程中，我使用 AI 辅助编写代码、生成测试用例、
排查问题。这里是详细的 AI 协作文档...
