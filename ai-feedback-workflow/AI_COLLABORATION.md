# AI 协作说明文档

## 🤖 本项目中 AI 的使用方式

### 1. 代码开发阶段

#### AI 辅助编程
- **用途**：生成基础代码框架、函数实现
- **Prompt 示例**：
  ```
  用 Python 写一个 HTTP 服务器，接收 POST 请求，解析 JSON 数据
  ```
- **排错记录**：
  - 问题：初始版本没有处理 JSON 解析错误
  - AI 建议：添加 try-except 块，返回友好错误信息

#### AI 代码审查
- **用途**：检查代码问题、优化建议
- **Prompt 示例**：
  ```
  检查这段代码的潜在问题和优化空间
  ```

---

### 2. 核心 AI 功能

#### 用户反馈分析
- **模型**：DeepSeek-V3（通过硅基流动 API）
- **能力**：
  - 文本分类（5 种类型）
  - 情感分析（3 种倾向）
  - 优先级判断（高/中/低）
  - 关键词提取
  - 行动建议生成

#### Prompt 设计
```python
prompt = f"""
你是一个专业的产品运营分析师。请分析以下用户反馈：

用户反馈："{feedback}"

请按照以下 JSON 格式返回分析结果...
"""
```

**设计要点**：
1. 明确角色定位（产品运营分析师）
2. 提供清晰的任务描述
3. 指定输出格式（JSON）
4. 给出判断标准

### 4. 排错过程

#### 问题 1：API 超时
**现象**：
```
requests.exceptions.Timeout: HTTPConnectionPool
```

**排查步骤**：
1. 检查网络连接 ✓
2. 检查 API Key 有效性 ✓
3. 增加 timeout 参数 → 从 10s 改为 30s ✓
4. 添加重试机制 ✓

**AI 协助**：
- 询问常见超时原因
- 获取重试机制代码示例

---

#### 问题 2：JSON 解析失败
**现象**：
```
json.decoder.JSONDecodeError: Expecting value
```

**原因**：
- API 返回的内容包含 markdown 代码块标记（```json）

**解决方案**：
```python
content = content.strip()
if content.startswith("```json"):
    content = content[7:-3]
```

**AI 协助**：
- 识别错误类型
- 提供字符串处理方案

---

#### 问题 3：分类不准确
**现象**：
- 部分投诉被分类为"功能建议"

**优化方案**：
1. 在 Prompt 中增加分类定义
2. 添加 few-shot 示例
3. 降低 temperature（0.7 → 0.3）

**AI 协助**：
- 分析错误案例
- 优化 Prompt 设计

## 🎯 关键学习

1. **Prompt 工程很重要** - 清晰的指令 = 更好的结果
2. **AI 输出需要验证** - 永远不要完全信任 AI 的输出
3. **人机协作最佳** - AI 生成 + 人工审核 = 高质量
4. **迭代优化** - 根据实际效果持续调整 Prompt
